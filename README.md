## 阅读提示

总分越高越好；3 个主指标为经过长度调整的会话失败标记率，越低越好。15 个细类百分比表示对应失败中的构成占比，不能当作绝对失败率；其官方排名按占比从高到低排列。主指标的派生排名、官方细类排名及可能排名范围在网页和工作簿中分别说明。

厂商排行采用该厂商总分最高的代表模型，不是厂商所有模型的平均值。
